# Edunet Token — Free Edu Token (EDT)

Solidity contracts for **Free Edu Token (EDT)** (`FEDToken`) and its token sale (`FEDTokenSale`), built with Truffle. Part of the [Edunet](https://github.com/Miken2001/edunet) project.
March 28 – April 1, 2021. Based on what I learned from the Dapp University token-sale course ([dapp-token-sale](https://github.com/Miken2001/dapp-token-sale)).

_Originally built before or around the time I created my GitHub account (May 2020). Recovered in 2026 from my old MacBook drive and imported here with the files' real dates._
